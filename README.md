#Scientific Calculator
A simple and easy-to-use Calculator made with python

#Description
This project is a scientific calculator made using Python language. It performs basic arithmetic operations on multiple numbers and can also perform many scientific or mathematical operations.

#Features
- Addition
- Subtraction
- Multiplication
- Division (Of two numbers only)
- Floor Division (Of two numbers only)
- Remainder (Of two numbers only)
- Square Root (Of one number only)
- Natural Logarithm (Of one number only)
- Custom Logarithm (Of one number only and the base should be positive)
- Factorial (Of one positive integer only)
- Highest Common Factor/ Greatest Common Divisor
- Value of any power of exponential (one power only)
- Value of Trigonometric functions (Of one angle in degrees only)
- Value of arcsine, arccosine, arctan in degrees (Of one number only)
- Change Values after any operation
- Easy-to-use and can operate until stopped be pressing 0

#Technologies Used
- Python
- Python built-in math module

#Requirements
- Python 3.14
- A Python compatible IDE or terminal

#Installation
1. Clone the Repository:
   git clone https://github.com/rishit221/Scientific-Calculator.git
2. Navigate to the repository
   cd Scientific-Calculator
3. Run the python program
   python project.py

#How To Use
1. Run the Python Program
2. Enter the Desired Values
3. Select the Desired Operation
4. The result is displayed on the screen
5. You can perform more operation with the same values, or change them, or you can exit the program by pressing 0
